# Pizza-Sales-Business-Performance-Analysis-Using-MYSQL-

📌 Project Overview

This project analyzes pizza sales data using MySQL to uncover business insights related to sales performance, customer ordering patterns, pizza categories, product popularity, and revenue contribution.

The project demonstrates how SQL can be used to transform transactional sales data into meaningful business insights that can support sales strategy, product performance analysis, and business decision-making.

🎯 Project Objective

The objective of this project is to analyze pizza sales data using MySQL and derive meaningful business insights related to sales performance, revenue generation, product demand, customer ordering patterns, and category performance.

The analysis aims to:

Evaluate overall order volume and revenue performance.
Identify the most popular and high-revenue pizza products.
Analyze pizza category and size-wise demand.
Examine order patterns across different hours of the day.
Measure average daily pizza sales and revenue contribution.
Analyze cumulative revenue trends over time.
Identify the top-performing pizza types within each category using advanced SQL techniques.

The overall goal is to demonstrate how SQL-driven data analysis can convert transactional sales data into actionable business insights that can support product planning, sales analysis, and data-driven decision-making.

🗂️ Dataset Structure

The project works with the following tables:

1. pizza_orders_table
Contains order-level information such as:
order_id
date
time

2. order_details
Contains individual pizza order details:
order_details_id
order_id
pizza_id
quantity

3. pizzas
Contains pizza-level information:
pizza_id
pizza_type_id
size
price

4. pizza_types
Contains pizza product information:
pizza_type_id
name
category
